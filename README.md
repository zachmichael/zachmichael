# Hi, I’m Zach 👋

I build and explore developer tools, automation, and interactive projects, with a particular interest in Workday, AI agents, and rhythm games.

## Projects I built

- [Canvas Kit Demo](https://github.com/zachmichael/workdayCanvasKitDemo) — an interactive React showcase of Workday Canvas Kit components.
- [Canvas Kit Demo for Extend](https://github.com/zachmichael/workdayCanvasKitDemoExtendVersion) — a companion Workday Extend app source bundle. Its README explains what has and has not been verified in a tenant.

## A fork I’ve adapted
